# 🌐 Повна специфікація та контент для вебсайту koshtu-web

Цей документ містить повну структуру, технічні вимоги, тексти юридичних сторінок (Privacy Policy, Terms of Use, Account Deletion) та концепцію маркетингового лендінгу для проєкту **koshtu-web**.

Сайт призначений для безкоштовного розгортання на платформі Vercel та є обов'язковою умовою для успішного проходження модерації додатка **Koshtu** в **Apple App Store Connect** та **Google Play Console**.

## 📁 1. Структура файлів у проєкті koshtu-web

Для розгортання створіть наступні файли у вашій папці `koshtu-web`:

- `index.html` — Головна сторінка (Landing Page + Waitlist)
- `privacy.html` — Політика конфіденційності (`/privacy`)
- `terms.html` — Умови використання та підтримка (`/terms`)
- `account-deletion.html` — Інструкція та форма видалення даних (`/account-deletion`)
- `README.md` — Інструкція розгортання

## 🔒 2. Тексти та структури юридичних сторінок

### 2.1. Політика конфіденційності (`privacy.html`)
> **Вимога сторів**: Обов'язкова сторінка для Apple App Store (Guideline 5.1.1) та Google Play Console (Data Safety Section). Доступна публічно без авторизації.

**Назва сторінки**: Політика конфіденційності (Privacy Policy)  
**Дата оновлення**: Листопад 2026 року  

**Зміст та розділи**:
1. **Основний принцип**: Мобільний застосунок Koshtu створений із дотриманням принципу Privacy-First. Фінансові дані належать виключно користувачу.
2. **Збір та збереження даних**: Застосунок працює за локальною моделлю (Offline-First). Усі записи про фінансові ліміти, щоденні витрати та параметри боргів/кредитів зберігаються безпосередньо у внутрішній пам'яті смартфона (AsyncStorage) та не передаються на зовнішні сервери.
3. **Використання аналітики та SDK**: Сторонні рекламні мережі чи трекери поведінки користувачів відсутні. У разі використання авторизації через Supabase або Sign in with Apple, дані обробляються виключно для забезпечення входу та синхронізації між власними пристроями.
4. **Права користувача та видалення даних**: Повний контроль над даними. Видалення записів відбувається миттєво в Налаштуваннях додатка або за запитом через сторінку Account Deletion.
5. **Контакти**: Служба підтримки Koshtu App (support).

### 2.2. Умови використання та підтримка (`terms.html`)
> **Вимога сторів**: Вимога App Store Connect для надання контенту підтримки (Support URL) та опису правил використання фінансових утиліт і підписок.

**Назва сторінки**: Умови використання (Terms of Use) та Підтримка  
**Дата оновлення**: Листопад 2026 року  

**Зміст та розділи**:
1. **Фінансове застереження (Disclaimer)**: Застосунок Koshtu є персональним калькулятором і трекером лімітів. Застосунок не надає професійних юридичних, банківських чи офіційних фінансових консультацій. Усі розрахунки відсоткових ставок боргів є орієнтовними та базуються на введених користувачем даних.
2. **Підписки та керування розрахунками**: У разі придбання розширених функцій (Premium) оплата здійснюється через офіційні платіжні системи Apple App Store або Google Play. Видалення додатка чи акаунту НЕ скасовує активні підписки автоматично. Керувати підписками або скасувати їх можна у налаштуваннях облікового запису Apple ID або Google Play.
3. **Специфікація підтримки**: Форма зв'язку та контактні дані для підтримки користувачів.

### 2.3. Сторінка видалення акаунту (`account-deletion.html`)
> **Вимога сторів**: Обов'язкова вимога Google Play Data Safety та Apple Guideline 5.1.1(v) для надання можливості видалення даних користувачам, які вже видалили додаток.

**Назва сторінки**: Видалення акаунту та персональних даних (Account & Data Deletion)

**Спосіб 1: Нативно всередині додатка (Найшвидший)**
Якщо додаток Koshtu встановлено на смартфоні:
1. Відкрийте застосунок Koshtu.
2. Перейдіть у розділ **Налаштування** (Settings).
3. Натисніть кнопку **«Видалити акаунт та дані»**.
4. Підтвердіть дію. Усі локальні записи та токени авторизації стираються миттєво.

**Спосіб 2: Запит через вебсайт (Якщо додаток уже видалено)**
Якщо додаток видалено і потрібно вилучити залишки профілю з серверів авторизації:
- Надішліть лист у службу підтримки з темою **«Запит на видалення акаунту»** та вкажіть електронну пошту, з якою відбувалася авторизація (Sign in with Apple / Google).
- Запит обробляється протягом 48 годин. Усі зв'язані токени авторизації анулюються, а хмарні записи видаляються остаточно.

*Примітка*: Видалення акаунту НЕ скасовує активні платіжні підписки. Скасувати підписку можна самостійно через налаштування облікового запису Apple ID або Google Play.

**Ключові блоки лендінгу**:

2. **Hero Section**:
   - Заголовок: *«Твій щоденний ліміт під контролем. Без стресу.»*
   - Підзаголовок: *«Koshtu вираховує безпечну суму витрат на кожен день та допомагає випереджати графік закриття боргів і кредитів.»*

3. **Bento Grid (Основні переваги)**:
   - **🎯 Денний ліміт**: Автоматичний розрахунок доступної суми на сьогодні на основі твоїх цілей та залишкових режимів.
   - **💳 Калькулятор боргів**: Зворотний зелений прогрес-бар. Відслідковуй кредити та зменшуй переплату банку.
   - **🔒 100% Приватність**: Офлайн-перша модель. Усі транзакції залишаються у твоєму телефоні.
4. **Footer**: Копірайт та юридичні посилання на `/privacy.html`, `/terms.html`, `/account-deletion.html`.

## ⚡ 4. Інструкція розгортання на Vercel

1. Ініціалізуйте Git у папці `koshtu-web`:
   ```bash
   cd koshtu-web
   git init
   git add .
   git commit -m "Add Koshtu web pages"
   ```
2. Запушьте код у свій репозиторій на GitHub (`koshtu-web`).
3. Перейдіть у **Vercel Dashboard** ➔ натисніть **Import Project** ➔ виберіть репозиторій `koshtu-web`.
4. Натисніть **Deploy**.
5. Скопіюйте згенеровані посилання для сторів:
   - **Privacy Policy URL**: `koshtu-web.vercel.app/privacy.html`
   - **Terms & Support URL**: `koshtu-web.vercel.app/terms.html`
   - **Account Deletion URL**: `koshtu-web.vercel.app/account-deletion.html`
